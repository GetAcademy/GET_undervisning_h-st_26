Introduksjon til MVC

Dagens plan:

  • Model View Controller (MVC)

    • Et design pattern for å separere ansvar (separation of concerns)
    • Model - Her bor de globale variablene. Kan deles opp i tre deler:
      • App: variabler som lagrer eller håndterer state på siden (eks hvem er logget inn, hvilken preferanser er satt, etc)
      • ViewState: mellomlagring av eks inputs. Ment for å “tømmes” og gjenbrukes.
      • Data: hvor dataen skal lagres (dummy database)
    • View - Det grafiske (HTML) som vises på skjermen.
      • Funksjoner og komponenter som genererer eller returnerer HTML anses som en view-funksjon.
    • Controller - Funksjoner som oppdaterer dataene i modellen.
      • "Hjelpefunksjoner" som endrer på variabler, og/eller som gjør "bakgrunnsarbeid" som ikke direkte synes på skjermen.

  • Eksempler

    • Endre på Clicker-eksempelet til å bruke MVC
    • Refaktorere Kinobillett-eksempelet til å bruke MVC
    • Lage et "gjenbrukbart" MVC-oppsett
